# ode

`sbmlutils.converters.ode` is a deprecated compatibility namespace for [sbmlsim-core](https://matthiaskoenig.github.io/sbmlsim-core/odes/), the ODE export of sbmlutils; its classes and functions are described in the [shared generator documentation](https://matthiaskoenig.github.io/sbmlsim-core/odes/). Import the API directly from `sbmlsim_core`. The guide is [ODE export](../ode.md).
