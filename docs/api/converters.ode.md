# ode

`sbmlutils.converters.ode` is a deprecated compatibility namespace for [sbmlode](https://matthiaskoenig.github.io/sbmlode/), the ODE export of sbmlutils; its classes and functions are described in the [API reference of sbmlode](https://matthiaskoenig.github.io/sbmlode/api/). Import the API directly from `sbmlode`. The guide is [ODE export](../ode.md).
