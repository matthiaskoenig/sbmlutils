# Interpolation

The interpolation API and its examples are moving from sbmlutils to `sbmlsim.interpolation`, alongside simulation workflows. The replacement is tracked in [sbmlsim PR #662](https://github.com/matthiaskoenig/sbmlsim/pull/662).

See [Migration](migration.md#interpolation) for the affected APIs and the status of the replacement. Existing SBML files with interpolation rules can still be read, written and validated.
