# Release notes for sbmlutils 0.16.0
![sbmlutils](https://github.com/matthiaskoenig/sbmlutils/raw/develop/docs/images/sbmlutils-logo-60.png)

We are pleased to release the next version of sbmlutils including the following changes. sbmlutils requires python 3.12 or later and sbmlode 0.2.0, which writes the ODE system in the native quantities of the SBML state variables.

## Breaking changes
- python 3.11 is no longer supported, sbmlutils requires python >= 3.12 (#PR)
- the ODE export is sbmlode 0.2.0 or later: a species is a state in amount or in concentration as the model declares it, also in a compartment whose size changes, and the system is never rewritten in the amounts of the species, so the markdown written by `create_model(create_markdown=True)` has no section `amounts`; see the [release notes of sbmlode 0.2.0](https://github.com/matthiaskoenig/sbmlode/blob/develop/release-notes/0.2.0.md) (#PR)
- `AnnotationType`, `AnnotationsType`, `OptionalAnnotationsType` and `UnitType` of `sbmlutils.factory` are `type` statements, i.e. instances of `typing.TypeAliasType`; an annotation reads the same, code which inspects an alias at runtime reads its value from `__value__` (#PR)

## Packaging and development
- `sbmlode>=0.2.0` is a dependency (#PR)
- the test matrix, the tox environments and the ruff target start at python 3.12, the tox environment `lowest` runs on python 3.12 (#PR)
